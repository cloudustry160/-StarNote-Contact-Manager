## 二、视频需要包含的内容（5–8 分钟）

不用写脚本，按顺序做一遍、全程不剪辑即可：

| 顺序 | 你要展示的 |
| --- | --- |
| 1 | 终端里 `npm run dev` 启动，浏览器打开 `localhost:5173`，首屏 5 条示例数据 |
| 2 | 新增一位联系人：填姓名，加 **2 个手机号 + 1 个邮箱 + 1 个微信 + 1 个地址**，设一个为主要，保存 |
| 3 | 编辑他：删掉中间一条联系方式再保存（证明动态行没串） |
| 4 | 打星收藏 → 切「收藏」标签页 → 刷新浏览器 → 收藏仍在；再取消一次 |
| 5 | 「导出」→ 用 Excel 打开文件，展示表头与「手机」列里的多值、`标签:值` |
| 6 | 在 Excel 里改两行：一行改名字，一行把手机号改成 `abc` → 保存 → 回页面「导入」→ 展示预览里的失败行与行号 → 确认导入 → Toast 汇总 |
| 7 | 搜索「张」→ 结果过滤；清空搜索 |
| 8 | 切到 390px 窄屏，展示移动端布局 |
| 9 | GitHub 提交历史 + Release `v1.0.0` 页面（可选，10 秒） |
| 10 | 手机流量打开 `http://114.55.128.202/addressbook/`，**镜头带到地址栏** |

## 三、录制注意

- **一定要出现地址栏**：本地是 `localhost:5173`，线上是 `114.55.128.202/addressbook`，这是「不是 localhost」的唯一证据。
- 不要静音后加速；解说可以用嘴说，字幕不重要。
- 导出/导入那一步**别跳过 Excel 打开的过程**，评审要看到文件真的能打开、列头正确。
- 失败行那次导入要停 2 秒，让画面停得住「第 21 行：手机号格式无效」。
- 录完直接传 B 站（设为公开/仅链接可见），把链接填进博客第 9 节。
