## 偏差原因小结

- **计划阶段**：起初按结对作业排期（约 54h），确认单人完成后重排为 28h，功能优先级被迫提前确定：三功能（收藏 25 + 多方式 10 + Excel 25）> 样式 > 部署。
- **导入功能**：真实 Excel 的脏数据（空行、全角冒号、全角分号混用、缺姓名）比设计时想的多，校验与错误定位占了最大一块。
- **部署**：服务器上已有计算器服务在跑，不能停、不能抢端口，多花时间在「查清现状 → 备份 → 只加 location → reload」这条稳妥路径上。
- **计划外成本**：本机环境问题（文件权限、npm 缓存目录）与 GitHub 间歇性连不上，各占用了一小段，但没有影响结果。

以实际开始/结束时间为准，按阶段累计；同一时段并行的工作记入占比最大的阶段。实际工时不含等待网络的时间。
